# Karousel KDE setup

Повторяемая настройка Karousel 0.17 для KDE Plasma 6: ширина колонок 50% / 100%, сочетания без перехвата занятых клавиш, закрепление ленты на одном мониторе и Geometry Change 1.5 для плавности.

Это личный комплект настроек с экспериментальной доработкой Karousel. Upstream не поддерживает несколько мониторов; здесь второй монитор остаётся для обычных свободных окон.

## Повторная установка

Нужны KDE Plasma 6 / KWin, `git`, `/usr/bin/python3` с модулем `dbus`, `kwriteconfig6` и QML-модули QtQuick, org.kde.kwin, org.kde.notification. Установщик не устанавливает системные зависимости. Запускайте из терминала своего сеанса KDE, **без sudo**.

```bash
git clone https://github.com/quynhter/karousel-kde-setup.git
cd karousel-kde-setup
/usr/bin/python3 setup_karousel.py --check
/usr/bin/python3 setup_karousel.py
```

По умолчанию лента закреплена на `eDP-1`, экране ноутбука. Для другого разъёма:

```bash
kscreen-doctor -o
/usr/bin/python3 setup_karousel.py --output HDMI-A-1
```

`--output` закрепляет Karousel за разъёмом; системный основной монитор KDE не меняется. При отключении выбранного экрана используется первый доступный; при подключении снова выбирается заданный разъём.

Все необходимые пакеты Karousel и Geometry Change встроены в установщик, поэтому после клонирования интернет для применения не нужен. Файл `karousel-primary-main.js` должен оставаться рядом с `setup_karousel.py`. Этот комплект намеренно закреплён на версиях 0.17 / 1.5, а не обновляется автоматически до последнего upstream.

## Управление

Meta — клавиша с логотипом Windows. Окна стоят колонками в горизонтальной ленте. Ширина 50% означает половину рабочей области с учётом отступов. Если в колонке несколько окон, её ширина меняется для всех сразу.

| Сочетание | Действие |
|---|---|
| **Meta+Enter** | Переключить ширину колонки 50% / 100% |
| **Meta+Ctrl+Page Down** | Половина ширины рабочей области |
| **Meta+Ctrl+Page Up** | Полная ширина рабочей области |
| **Meta+Ctrl+Alt+← / →** | Выбрать соседнее окно и прокрутить к нему ленту |
| Meta+Ctrl+Alt+↑ / ↓ | Перейти к окну выше / ниже внутри колонки |
| **Meta+Space** | Вынуть окно из ленты / вернуть в ленту |
| Meta+Ctrl+Enter | Поставить выбранное окно по центру |
| Meta+Alt+Shift+← / → | Переместить окно в соседнюю колонку |
| Meta+Alt+Shift+↑ / ↓ | Переместить окно по вертикали |

Установщик отключает прочие сочетания Karousel. Штатные сочетания KDE не меняются. Перед применением он проверяет сохранённые и активные глобальные сочетания и останавливается при конфликте с другой командой. Локальные сочетания отдельных приложений эта проверка не анализирует.

Штатные команды KDE:

- `Meta+Page Up` — настоящее разворачивание окна; `Meta+Backspace` — восстановление. Если окно уже развёрнуто, сначала восстановите его, затем меняйте ширину колонки.
- `Meta+Page Down` — свернуть окно, а не уменьшить ширину.
- `Meta+← / →` — привязать свободное окно к половине экрана. Для окна в ленте сначала нажмите `Meta+Space`, если хотите использовать обычную привязку KDE.
- `Alt+Tab` — обычное переключение между окнами.

Попробуйте открыть два окна на основном экране и задать каждому половину ширины. Затем откройте третье и переходите по ленте `Meta+Ctrl+Alt+← / →`.

## Работа со вторым монитором

Новые окна на втором мониторе остаются свободными. Для переноса из ленты сначала нажмите `Meta+Space`, затем перетащите окно на второй экран или используйте штатное `Meta+Shift+→`. Для возвращения перенесите свободное окно на основной экран и нажмите `Meta+Space`. На втором экране команда Karousel `Meta+Space` ничего не делает.

Доработка показывает только колонки, целиком помещающиеся в рабочей области основного монитора. Остальные перемещает за левую границу **всех** экранов, сохраняя их логическое положение в ленте. При выборе колонки лента прокручивается и возвращает её в рабочую область. Части соседних колонок у края не отображаются. Это обход ограничения, не отдельная лента для каждого монитора. После обновления Karousel доработка может быть перезаписана.

Geometry Change включается с длительностью 200 мс. Внешние отступы и горизонтальный промежуток — 8 логических пикселей.

## Резервная копия и откат

Перед изменениями установщик создаёт `backups/<дата-время>/` с прежними файлами и сочетаниями. При ошибке применения он пытается выполнить автоматический откат. Также он выводит точную команду для ручного отката:

```bash
/usr/bin/python3 setup_karousel.py --restore backups/<дата-время>
```

Замените `<дата-время>` на имя своей резервной копии. Откат восстанавливает `kwinrc` **целиком**, каталоги обоих дополнений и прежние сочетания Karousel. Выполняйте его вскоре после проверки: изменения других настроек `kwinrc`, сделанные после резервной копии, тоже будут заменены. Полная копия `kglobalshortcutsrc` сохраняется для ручного восстановления; автоматически целиком она не заменяется.

Резервные копии содержат личные настройки и исключены из Git через `.gitignore`. Не добавляйте их в публичный репозиторий. При переустановке системы сохраняйте резервные копии отдельно, если они нужны: репозиторий воспроизводит эту настройку, а не весь старый сеанс KDE.

## Проверка

```bash
/usr/bin/python3 setup_karousel.py --check
node tests/test-primary.cjs karousel-primary-main.js
```

Модельные тесты проверяют выбор экрана, исключение окон второго монитора, размещение переполняющих колонок за пределами всех экранов, возвращение окна, защиту развёрнутого окна и запасной экран. Они не заменяют визуальную проверку в KWin / Wayland.

После установки проверьте три окна в ленте, размеры 50% / 100%, перенос свободного окна между мониторами и переподключение экрана. Если KWin возвращает убранные окна на видимый экран или появляются скачки, используйте откат.
